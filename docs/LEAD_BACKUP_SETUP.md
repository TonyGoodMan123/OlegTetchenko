# 📋 Настройка резервного сохранения заявок — Google Sheets

> **Это временная страховка** на случай недоступности Telegram.  
> После настройки каждая заявка с сайта будет гарантированно сохраняться в таблицу Google Sheets и приходить на почту, **независимо от состояния Telegram и Яндекс.Облако**.

---

## Что это делает

```
Форма сайта
  ├── Telegram (через Яндекс.Облако) — может падать
  └── Google Sheets (через Apps Script) — ВАШ СТРАХОВОЙ КАНАЛ
             ↓
         Строка в таблице "Заявки сайта Олег"
             ↓
         Письмо на вашу почту
```

Если Telegram не работает — заявка всё равно сохраняется в таблицу.

---

## Что потребуется

- Google-аккаунт (обычный @gmail.com)
- Около **15–20 минут** времени
- Никаких знаний программирования не нужно

---

## Шаг 1 — Создать Google-таблицу

1. Откройте [Google Sheets](https://sheets.google.com)
2. Нажмите **«+»** (Создать новую таблицу) или **«Пустой файл»**
3. В верхнем левом углу, где написано «Без названия», нажмите и введите название:  
   **`Заявки сайта Олег`**
4. Нажмите **Enter** для сохранения названия
5. Внизу страницы переименуйте лист `Лист1` → **`Leads`**:  
   → правая кнопка мыши по вкладке `Лист1` → **«Переименовать»** → введите `Leads` → Enter

> **Важно:** Название таблицы и лист `Leads` создаются автоматически скриптом при первом запуске. Если хотите — можете пропустить п.5 и оставить `Лист1` (скрипт сам создаст `Leads`).

---

## Шаг 2 — Открыть Apps Script

1. В таблице (которую только что создали) нажмите в верхнем меню:  
   **Расширения → Apps Script**  
   *(или: Extensions → Apps Script, если интерфейс на английском)*
2. Откроется новое окно/вкладка с редактором кода

---

## Шаг 3 — Вставить код

1. В редакторе Apps Script вы увидите вкладку **Code.gs** с пустой функцией
2. **Выделите весь текст** в редакторе (Ctrl+A или Cmd+A)
3. **Удалите** выделенное
4. Откройте файл из репозитория: `google-apps-script/Code.gs`
5. Скопируйте **весь** его содержимое (Ctrl+A → Ctrl+C)
6. Вставьте в редактор Apps Script (Ctrl+V)

---

## Шаг 4 — Указать email для уведомлений

В вставленном коде найдите строку (она в самом начале, примерно строка 18):

```javascript
  EMAIL_TO: '',  // Например: 'oleg@example.com'
```

Замените пустые кавычки `''` на ваш email:

```javascript
  EMAIL_TO: 'ваш_email@gmail.com',
```

Например:
```javascript
  EMAIL_TO: 'oleg.tetchenko@gmail.com',
```

> Именно на этот адрес будут приходить письма при каждой новой заявке.

---

## Шаг 5 — Сохранить

Нажмите кнопку **💾 Сохранить** (иконка дискеты) или **Ctrl+S** / **Cmd+S**.

---

## Шаг 6 — Опубликовать как Web App

1. Нажмите кнопку **«Развернуть»** (или **Deploy**) в правом верхнем углу
2. В выпадающем меню выберите **«Новое развёртывание»** (New deployment)
3. Нажмите шестерёнку ⚙️ рядом с «Тип» и выберите **«Веб-приложение»** (Web app)
4. Заполните поля:
   - **Описание**: `Lead backup v1`
   - **Выполнять как** (Execute as): **`Я (ваш email)`** — выберите свой аккаунт
   - **Кто имеет доступ** (Who has access): **`Все`** (Anyone) — это важно! Без этого форма не сможет отправлять данные
5. Нажмите **«Развернуть»** (Deploy)

---

## Шаг 7 — Разрешить доступ

1. После нажатия Deploy появится окно **«Разрешение доступа»**
2. Нажмите **«Разрешить доступ»** (Authorize access)
3. Выберите ваш Google-аккаунт
4. Появится предупреждение **«Google не проверил это приложение»**  
   → Нажмите **«Дополнительно»** (Advanced) в левом нижнем углу  
   → Нажмите **«Перейти на Lead backup v1 (небезопасно)»**  
   → Нажмите **«Разрешить»** (Allow)

> ⚠️ Это предупреждение нормально — оно означает, что приложение написано не Google, а вами. Ваши данные в безопасности.

---

## Шаг 8 — Скопировать URL

1. После успешного Deploy появится диалог с **URL веб-приложения**
2. Он выглядит примерно так:  
   `https://script.google.com/macros/s/AKfycb.../exec`
3. **Скопируйте этот URL** — он понадобится на следующем шаге
4. Нажмите **OK** / **Готово**

> **Важно:** Сохраните этот URL — потом его можно найти в Deploy → Manage deployments.

---

## Шаг 9 — Добавить URL в проект

1. В корне проекта создайте файл **`.env`** (если его нет)  
   *(можно скопировать `.env.example` и переименовать)*
2. Откройте `.env` и найдите строку:  
   ```
   VITE_BACKUP_LEADS_URL=
   ```
3. Вставьте скопированный URL после `=`:  
   ```
   VITE_BACKUP_LEADS_URL=https://script.google.com/macros/s/AKfycb.../exec
   ```
4. Сохраните файл

---

## Шаг 10 — Пересобрать и задеплоить сайт

После добавления `.env` нужно пересобрать сайт, чтобы URL попал в код:

```bash
npm run build
```

Затем задеплойте папку `dist/` на хостинг как обычно.

---

## Шаг 11 — Проверить работу

### Быстрая проверка (healthcheck)

Откройте в браузере ваш Apps Script URL:  
`https://script.google.com/macros/s/ВАШ_ID/exec`

Должен вернуться ответ:
```json
{"ok":true,"service":"lead-backup","version":"1.0.0"}
```

### Полная проверка (тестовая заявка)

1. Откройте сайт
2. Нажмите **«Записаться»** любым способом
3. Введите тестовые данные: имя = `Тест`, телефон = `+7 999 000-00-00`
4. Поставьте галочку согласия
5. Нажмите **«Записаться»**
6. Форма должна показать зелёную галочку «Запись принята!»
7. Откройте таблицу **«Заявки сайта Олег»** — в листе **Leads** должна появиться строка
8. На указанный email должно прийти письмо **«Новая заявка с сайта»**

### Проверка в консоли браузера

Нажмите F12 → вкладка Console и отправьте форму. Вы увидите:
```
[leadBackup] ✅ Saved to Google Sheets. lead_id: lead_YYYYMMDD_...
[Modal] submit результат: { lead_id: ..., telegram: "failed", backup: "saved" }
```

## Структура таблицы Leads

| Колонка | Описание |
|---------|----------|
| `lead_id` | Уникальный ID заявки (автогенерируется на клиенте) |
| `created_at` | Дата и время получения (UTC ISO) |
| `name` | Имя клиента |
| `phone` | Телефон клиента |
| `page_url` | Полный URL страницы, с которой отправлена форма |
| `referrer` | Откуда пришёл пользователь |
| `utm_source` | Источник рекламы |
| `utm_medium` | Канал рекламы |
| `utm_campaign` | Название кампании |
| `utm_content` | Содержание объявления |
| `utm_term` | Ключевое слово |
| `yclid` | ID клика Яндекс.Директ |
| `telegram_status` | Статус отправки в Telegram (`sent` / `failed` / `pending`) |
| `user_agent` | Браузер/устройство пользователя |

## Если что-то пошло не так

### Форма отправляет, но строка не появляется в таблице

1. Проверьте, правильно ли вставлен URL в `.env`
2. Убедитесь, что выполнили `npm run build` после изменения `.env`
3. Откройте Apps Script → вкладка **Выполнение** (Executions) — там видны все вызовы и ошибки

### Ошибка «Неавторизован» / «Unauthorized»

→ При Deploy выбрали **«Только я»** вместо **«Все»**. Нужно создать новое развёртывание с правильными настройками.

### Письма не приходят

1. Проверьте, правильно ли указан `EMAIL_TO` в коде Apps Script
2. Проверьте папку «Спам» в почте
3. В Apps Script → Выполнение → найдите последний вызов → посмотрите логи

### Как обновить код скрипта

1. Откройте Apps Script
2. Измените код
3. Нажмите **Deploy → Manage deployments → Edit** (карандаш) → **Version: New version** → **Deploy**

---

## Безопасность

- URL Apps Script является публичным (доступен всем), но он только **принимает POST** с данными формы
- Скрипт **не может читать** другие ваши Google-документы
- Honeypot-поле отсекает базовых спам-ботов
- Все поля проверяются и очищаются на стороне скрипта
- Данные хранятся **только в вашей** Google-таблице
