## 📋 Пошаговая инструкция

### Шаг 1: Добавить бота в группу (если еще не добавлен)

1. Откройте Telegram
2. Найдите бота: **@OlegSiteBot**
3. Перейдите в вашу группу (chat_id: `-1003496210379`)
4. Добавьте бота в группу:
   - Нажмите на название группы → "Добавить участников"
   - Найдите @OlegSiteBot
   - Добавьте бота
5. **ВАЖНО**: Убедитесь, что бот может отправлять сообщения

### Шаг 2: Создать Worker в Cloudflare

1. Откройте [Cloudflare Dashboard](https://dash.cloudflare.com/)
2. Перейдите в **Workers & Pages** (левое меню)
3. Нажмите **Create** → **Create Worker**
4. Укажите имя: `olegweb-lead-to-telegram-api`
5. Нажмите **Deploy**

### Шаг 3: Добавить код Worker

1. После создания Worker откроется редактор кода
2. Удалите весь существующий код
3. Откройте файл `cloudflare-worker/worker.js` в вашем проекте
4. Скопируйте **весь код** из файла
5. Вставьте в редактор Cloudflare
6. Нажмите **Save and Deploy**

### Шаг 4: Добавить секрет BOT_TOKEN

1. В настройках Worker перейдите в **Settings** (вкладка сверху)
2. Прокрутите до раздела **Variables and Secrets**
3. Нажмите **Add variable**
4. **ВАЖНО**: Выберите тип **Secret** (не Text!)
5. Заполните:
   - **Variable name**: `BOT_TOKEN`
   - **Value**: `ВАШ_НОВЫЙ_ТОКЕН_ОТ_BOTFATHER` (перевыпущенный)
6. Нажмите **Encrypt**
7. Нажмите **Save and Deploy**

### Шаг 5: Проверить URL Worker

1. Перейдите на вкладку **Settings** → **Triggers**
2. Проверьте URL вашего Worker
3. Он должен быть: `https://olegweb-lead-to-telegram-api.scorcioner.workers.dev`
4. Если URL отличается:
   - Скопируйте новый URL
   - Откройте `src/utils/telegram.js`
   - Замените значение `WORKER_URL` на новый URL

## 🐛 Если что-то не работает

### Ошибка "Server configuration error"
**Причина**: BOT_TOKEN не добавлен или добавлен неправильно

**Решение**:
- Убедитесь, что выбрали тип **Secret**, а не Text
- Проверьте, что имя переменной: `BOT_TOKEN` (заглавные буквы)
- Пересохраните и передеплойте Worker

### Ошибка "Failed to send message to Telegram"
**Причина**: Бот не может отправить сообщение в группу

**Решение**:
- Убедитесь, что @OlegSiteBot добавлен в группу
- Проверьте, что chat_id правильный: `-1003496210379`
- Попробуйте отправить любое сообщение боту в личку, а потом снова в группу

### Ошибка CORS в консоли браузера
**Причина**: Worker блокирует запросы

**Решение**:
- Проверьте, что код Worker скопирован полностью
- Убедитесь, что в коде есть CORS headers

### Ничего не происходит / форма не отправляется
**Причина**: Неправильный URL Worker

**Решение**:
- Проверьте URL Worker в Cloudflare
- Обновите `WORKER_URL` в файле `src/utils/telegram.js`
